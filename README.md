# RecallApp

### An app for memorizing information using the spaced repetition method.

</div>

---

**RecallIt** is an app for memorizing information using the **spaced repetition** method. Users create decks of flashcards featuring questions and answers on topics such as language learning, exam terminology, or formulas — and complete short review sessions.

>  **Spaced repetition** is a technique for effective learning in which material is reviewed at gradually increasing intervals.
